# Deliver releases by approved GHCR digest

Minori builds each release once on a GitHub-hosted runner, publishes the public-source image to GHCR, and deploys only its immutable digest after Production Approval through a restricted, versioned SSH command. This replaces Vultr source builds and avoids a production self-hosted runner: CI and production use the same artifact, while the stable server entrypoint preserves preflight, additive migration, readiness, rollback, and a current-plus-two-predecessor Local Rollback Set. The same operator may create the protected release tag and approve production, so the first release is a two-step safeguard rather than separation of duties. If GitHub's release control plane is unavailable, Minori keeps the current healthy release running instead of adding a second emergency deployment protocol.
